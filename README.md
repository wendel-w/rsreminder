# RsReminder

This is a simple cli tool to print random bible verses or quotes.

## Description

The program selects and prints random verses/quotes from a config file.


## Installing

*  Install it with cargo
```bash
cargo install rsreminder
```
* And don't forget to copy `config.toml`, its a template config, with some extra documentation.
* Not tested on Windows and MacOS, but theoretically should work. 

### Run the program

* To see it in action just run:
```bash
rsreminder
```
* TIP: You can also put this command inside your or your shells config file to see it every time you open the terminal.
